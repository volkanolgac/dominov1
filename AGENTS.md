# MİNİ DOMİNO

A native Android Domino game built with Kotlin and Jetpack Compose.

## Core Features
- **Tactical AI**: Challenging opponent with smart move selection.
- **Classic Gameplay**: Support for standard domino rules (Draw game).
- **Responsive UI**: Built with Jetpack Compose for a smooth experience.
- **Sound Effects**: Native audio feedback for game events.
- **Local Stats**: Tracking wins, losses, and high scores.

## Architecture
- **MVVM**: Separation of concerns between UI and business logic.
- **DominoEngine**: Core game logic for deck generation, shuffling, and move validation.
- **DominoViewModel**: Manages the game state and UI interactions.

## Deployment
- Compiled with Android SDK 36 and JDK 21.
- Uses Material 3 design system.
